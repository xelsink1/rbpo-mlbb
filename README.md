Подготовлены документы S01–S05 и минимальная техническая основа: ASP.NET Core API и PostgreSQL в Docker Compose. Единственный маршрут `GET /health` проверяет соединение с БД и возвращает фиксированный `200/ready` либо `503/unavailable`. API доступен через `127.0.0.1`, порт БД не опубликован.

Техническая основа проверена на незакоммиченных исходниках S05: запуск, остановка и зависание БД, восстановление, повторный запуск и сохранность тома. Регистрация, сеансы и предметные сценарии пока не реализованы; будущие проверки D остаются планами.

Для первого запуска подготовьте локальный `.env` по [примеру](.env.example), замените пароль и выполните `docker compose up --build -d --wait --wait-timeout 120`. Ожидаемый запрос — `curl.exe http://127.0.0.1:8080/health`; при занятом порте задайте другой `API_PORT`. Полная инструкция находится в паспорте. [Скрипт](scripts/verify.ps1) проверяет основу в отдельном окружении.

Запись AI Usage за S05 добавлена; личная проверка документов, исходников и обычного запуска M2 подтверждена. Фиксация окончательного commit, публичная доступность сдаваемой версии, срок и канал сдачи, регистрация команды и содержательные проверки D-03/D-04 участниками ещё требуют завершения.
